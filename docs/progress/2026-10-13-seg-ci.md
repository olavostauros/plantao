# 2026-10-13 — Segurança do CI (P-004, P-005)

Correção de dois achados da auditoria de segurança de 2026-10-13 (relatório
`docs/security/reports/2026-10-13-completa.md`, ainda fora do `main`).

## Feito
- **P-004**: as quatro actions do `pages.yml` fixadas pelo SHA do commit, com a versão exata em
  comentário. SHAs resolvidos de novo hoje com `gh api repos/actions/<action>/git/ref/tags/<tag>`
  (seguindo tag anotada até o commit), e a versão exata achada entre as tags que apontam para o
  mesmo commit: checkout v4.4.0, setup-node v4.4.0, upload-pages-artifact v3.0.1, deploy-pages
  v4.0.5. Mesmo major de antes; subir de major fica para outro PR.
- **P-005**: o job `automerge` passa `--match-head-commit "$HEAD_SHA"` (`HEAD_SHA` =
  `github.event.pull_request.head.sha`) ao `gh pr merge`: se o branch andou depois do build, o
  merge falha.
- `tests/workflow.test.ts` segura as duas regras (conferido: falha com o `pages.yml` antigo).
