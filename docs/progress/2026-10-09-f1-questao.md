# 2026-10-09 — F1: a página de questão

## Feito
- Renderizador do Markdown restrito (`src/lib/markdown.ts`, decisão 0005) com testes de cada
  elemento permitido e proibido, incluindo "de R$ 5 e de R$ 20" como texto.
- `/questao/<id>/` para as 65 do seed (`QuestionView.astro`): texto-base, enunciado (comando do
  Cebraspe separado), alternativas, gabarito em `<details>`, aviso de anulada, alterada com o
  preliminar, fonte oficial (prova, data, página, PDF), assuntos, anterior/próxima da prova.

- Layout `Base.astro` (cabeçalho, rodapé, "Pular para o conteúdo"), tokens novos (`line`,
  `surface`, `ok`, `bad`) e estilos do conteúdo `.md` em `global.css`.
- Entrada provisória lista as provas com links para cada questão.
- Testes de página com a container API do Astro (`vitest.config.ts` usa `getViteConfig`): todas
  as 65 sem JS e uma fixture com textos longos do tamanho dos reais (`tests/fixtures/`).
